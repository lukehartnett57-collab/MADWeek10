# MAD Week 10 – Reading Data from Firestore (Todo App)

## 1. Lab Overview

In Lab 08 you connected a React Native app to Firebase.
In Lab 09 you **wrote** data to Firestore.
In this lab you will **read that data back** and display it in the app.

You will build a simple **Todo App** where a user can:

1. Type a todo and save it to Firestore (**Create**, revision from Lab 09)
2. See all saved todos in a list (**Read**, new in this lab)
3. Close and reopen the app and still see the todos, because they are stored in the cloud

## 2. Learning Outcomes

By the end of this lab you will be able to:

- Explain the Firestore structure: **collection → document → fields**
- Write data with `addDoc()`
- Read data with `getDocs()` and convert documents into JavaScript objects
- Display Firestore data using `FlatList`
- Use `useState` and `useEffect` to load data when a screen opens
- Handle loading and empty states

### Part 4: Read the Todos 

This is the main goal of the lab.

1. In `todoService.js`, complete **TODO 2** to fetch all documents from `todos`.
2. In `App.js`, complete **TODO 3** to call `fetchTodos()` when the screen first opens (`useEffect`).

Key idea: Firestore returns **snapshots**, not plain objects.
You must convert each document yourself:

```js
snapshot.docs.map((doc) => ({ id: doc.id, ...doc.data() }))
```

## 5. Firestore Rules (test mode only)

For this lab, use these rules (Firebase Console → Firestore → Rules):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /todos/{doc} {
      allow read, write: if true;
    }
  }
}
```

> These rules let anyone read and write. They are fine for learning only.
> A real app must restrict access (we will cover authentication later).

## 6. Common Problems

| Problem                                   | Likely cause and fix                                           |
|-------------------------------------------|----------------------------------------------------------------|
| `Missing or insufficient permissions`     | Check the Firestore rules above and press **Publish**          |
| `No Firebase App '[DEFAULT]' created`     | `firebaseConfig.js` is not imported or has wrong values        |
| List is empty but console has data        | Collection name mismatch (`todos` vs `Todos`)                  |
| `Unable to resolve "firebase/firestore"`  | Run `npm install firebase`, then restart with `npx expo start -c` |
| Each item warns about missing `key`       | Use `keyExtractor={(item) => item.id}`                         |
